Week 2: Data Exploration and Visualisation

During Week 2, I focused on exploring and understanding datasets using Python. I performed data cleaning and exploratory data analysis (EDA) to identify patterns, trends, missing values and relationships within the data. I also created visualisations and charts to communicate insights clearly and make the data easier to understand. This helped me develop practical skills in data analysis, data interpretation and presenting information visually.

Week 3: SQL and Performance Dashboard

During Week 3, I worked with a mock NextGenLearners database using SQLite and SQL. I created and explored related database tables, wrote SQL queries using operations such as JOIN, GROUP BY, aggregate functions and LEFT JOIN to analyse applicant and intern performance. I then used Python, Pandas and Streamlit to develop an interactive dashboard. The dashboard presents applicant and intern statistics, completion rates, hackathon scores and a top-performing interns leaderboard, with a domain filter for exploring results.

Tools and Technologies

Python: Data analysis and dashboard development.

Pandas: Data manipulation and analysis.

SQL / SQLite: Database creation, querying and analysis.

Matplotlib / Seaborn: Data visualisation (Week 2).

Streamlit: Interactive dashboard development (Week 3).

Note: Week 3 uses fictional mock data for demonstration and analysis purposes.
